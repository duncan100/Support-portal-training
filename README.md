# Support-portal-training
Internal support portal documentation for the Northstar support team

### About 
This repo is used by the Northstar support team for onboarding and internal training .

## Getting started 
### Prerequisites

 -Git
 
 -Python 3.10 OR Newer

 ##Setup
 1. download or clone the project files.
 2. open the 'support-portal-training' project folder.
 3. Check that python is installed by running 'python --version'.

 4. ## Run the project

    Start the support portal by running 'python app.py'
    
    Open 'http://localhost:8000' in your browser
    
    confirm that the Northstar support portal page appears.
